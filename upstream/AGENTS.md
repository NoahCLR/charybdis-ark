# Imported inputs

Read `README.md` and `manifest.json` before changing files here. Fixtures and
QMK inputs are pinned source copies, not app-owned code. Update from a reviewed
upstream commit, retain source notices, and update provenance and checksums in
the same change. Documentation may rewrite links as recorded in the manifest.
Do not change expected bytes to make a failing app test pass. Never introduce
symlinks to sibling repositories. Keep runtime imports out of this directory.
