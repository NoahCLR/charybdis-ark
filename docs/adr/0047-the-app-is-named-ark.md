# The app is named Ark

Cited as D-L47.

"Charybdis Live" named a feature, live editing, and read ambiguously as the product, so the app is Charybdis Ark: "Ark" in running text, `charybdis-ark` for the repository and package, `charybdisArk.*` for commands and `CHARYBDIS_ARK_ROOT` for the bridge. Ark stands for **Adjust, Review, Keep**: adjust a draft, review its changes, keep them on the keyboard. The feature keeps its own words (live editing, the live profile), and backups keep `.charybdis.json` because it names the keyboard, not the app. VS Code keys an extension's storage by its identity, so on start the extension copies recovery copies saved under `noah.charybdis-live` and `noah.charybdis-live-v2` into its own storage, never moving or overwriting one.
