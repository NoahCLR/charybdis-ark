# The Keyboard group's screen is About

Cited as D-L108.

The rail's last group, **Keyboard**, held two screens, **Backups** and
**Keyboard**, so the rail read the same word twice, once as the group's
heading and once as a screen under it. The screen is now **About**, on the
rail and wherever a link offers it (`secondaryLabel`,
`webview/view/screens.mjs`), and the guide, the glossary and the specs call
it the About screen.

What it holds is what an operating system's "About this computer" holds: the
keyboard's name as its title, the firmware it runs and whether it works with
this Ark, Ark's own version, its two halves, and how full its memory is.
Under the Keyboard heading it reads as being about this keyboard. Only the
word changes: the screen's id stays `device`, its renderer `screenDevice`,
and the group keeps its heading, Keyboard.

## Considered options

**Status**: it fits the halves and the memory, but not renaming the keyboard
or reading which firmware it runs.

**This keyboard**: it is the name of the screen's first panel, so it would
move the repeat inside the screen.

**Device**: a word Ark uses nowhere else that a person reads.

Renaming the group instead: Backups and this screen are both about the
keyboard, and a vaguer heading, such as Manage, would say less.
