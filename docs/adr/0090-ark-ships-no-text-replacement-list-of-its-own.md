# Ark ships no text replacement list of its own

Cited as D-L90.

A person's text replacement list is what they add and what they import, nothing else (Noah, 2026-11-10). Ark used to offer **Add common typo fixes** on an empty list: some 200 English words written for Ark with about 400 ways they are mistyped, added like a file. It went, with everything that existed only for it: the button and its words, the list's data in `core/data/`, its import path and the size the model published for it, and the test that held no input in it was an English word, with the SCOWL word list that test read.

A pre-made list is someone else's typos: the ones a person makes are their own, and a fix they never make costs a word they might mean. It is English only, on a keyboard Ark supports on fifteen host layouts. And it is one more thing to keep correct, against a matcher and its rules that change with the firmware. An empty list now offers **+ New replacement** and **Import…**, with a line that says what a file can be; Export and Import still carry a list from one keyboard or person to another (D-L85).

## Considered options

Keeping the list behind a smaller control, or in the guide as a file to download: the same list to keep correct, offered as Ark's own. Lists per language: more of what this removes.
