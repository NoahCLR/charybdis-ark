# Spacing is set from one scale

Cited as D-L79.

Every padding, margin and gap in the stylesheet is a token from one spacing scale, as every font size, weight, radius, layer and colour already was. Until now spacing was the one size written by hand: 35 distinct pixel values, 150 of them odd (1, 3, 3.5, 5, 7, 9, 11, 13, 15), each tuned by eye in the rule that used it, so the same gap drifted by a pixel or two between lists, cards and rows, and nothing stopped the next rule from adding a 36th value. The scale is a 4-point ladder, `--sp-hair` 1 · `--sp-0` 2 · `--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-5` 20 · `--sp-6` 24 · `--sp-7` 32 · `--sp-8` 48. Odd values rounded to the nearest step. The even values between rungs (6, 10, 14, 18), which the old rhythm used in 230 rules, were placed one by one by what they space: a gap inside a control (a swatch to its name, a dot to its word, a label to its field, the parts of a tab) stepped down, so controls stay compact, and a gap between sibling controls or the padding around content stepped up, so cards and rows breathe. An input's side padding is 12, and a number field's width (`.input.num`) carries that. A width an input keeps for what rides inside it (its unit, a select's arrow, a name's byte count), the check body's indent and the page's room above the commit bar are not rhythm and are named tokens of their own (`--unit-room`, `--select-room`, `--count-room`, `--check-indent`, `--commit-pad`). A rule may write 0, `auto`, a token, or a `calc()`, `max()` or `min()` on one; `tests/scripts/conventions.test.js` refuses anything else, as it refuses a raw font size. The contract is in [Shared controls](../spec/interface-contracts.md#shared-controls).

## Considered options

Leaving spacing untokenised, the rule this replaces: the one gap in an otherwise complete token discipline, and the source of the pixel drift between screens. Keeping 6, 10, 14 and 18 as four half steps between the rungs: what the first migration did, so that no rule moved by more than a pixel; but a scale with four "temporary" rungs is an exception that never leaves, and retiring them later would have meant a second interface-wide shift instead of one. A 2-point ladder throughout: no rounding at all, but twenty rungs is a list of values, not a scale, and it keeps every odd pixel the eye cannot tell apart. Spacing utilities on the markup (`.gap-8`, `.p-12`): the stylesheet already has a few for rows and stacks; moving every gap there scatters layout across the templates that the stylesheet keeps in one place.
