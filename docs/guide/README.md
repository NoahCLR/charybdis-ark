# Ark guide

How to use Ark, screen by screen. Start with connecting; after that, read the
page for whatever you want to change.

1. [Connecting](connecting.md): installing Ark, reading the keyboard, the
   demo and the Keyboard screen.
2. [The board and layers](board-and-layers.md): the board, the hover card,
   layer tabs, previewing layers together, renaming and reordering layers.
3. [Keys](keys.md): what a key sends, the keycode picker, custom keys (and
   swapping their slots) and keyboard-wide key swaps.
4. [Behaviours](behaviours.md): what a key does on tap, hold and long hold,
   for each tap count, and its timing.
5. [Combos](combos.md): keys pressed together.
6. [Macros](macros.md): text and key sequences, swapping slots, recording,
   and your computer's keyboard layout.
7. [Autocorrect](autocorrect.md): the typos the keyboard fixes as you
   type, each correction with the ways you mistype it, the starter list,
   and importing and exporting a list.
8. [Pointing](pointing.md): the trackball's speed, sniping and auto-mouse,
   and the 32 pointing modes.
9. [Lighting](lighting.md): the background effect, layer and mode colours,
   feedback and the idle timeout.
10. [Review and save](review-and-save.md): the edit modes (Live edit, Live
    preview + save and Review and save), Review and its checks, and what
    happens while the keyboard saves.
11. [Backups](backups.md): exporting and importing profiles, and the recovery
    copies Ark keeps.
