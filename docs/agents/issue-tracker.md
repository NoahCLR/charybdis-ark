# Issue tracker

Issues for this repository live in Noah's private notes vault,
`charybdis-notes`, not on GitHub. From any checkout or worktree it is:

```sh
"$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")/../charybdis-notes"
```

Its `_agents/tracker.md` maps every tracker operation the skills name
(publishing an issue, a spec or tickets, fetching a ticket, claiming,
wayfinding) onto its notes, tasks and plans; read it before running one. Its
`AGENTS.md` governs working in the vault. Pull requests are public: never link
or quote the vault from one.

Without the vault on this Mac, there is no tracker: say so and stop rather than
filing issues elsewhere.
